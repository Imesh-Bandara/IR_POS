# IR POS Windows Build Guide

## Build environment

This project is configured for a Windows desktop installer, but the actual build and packaging verification in this environment was executed on macOS.

- Host OS: macOS Darwin 25.6.0
- CPU architecture: arm64
- Node.js: v25.2.1
- npm: 11.6.2
- Rust: 1.98.1
- Tauri CLI: 2.11.5
- Intended Windows target: x86_64-pc-windows-msvc
- Product identity: IR POS / IR Fusions / com.irfusions.irpos / 1.0.0

## Configured packaging target

The project is configured for a Windows NSIS installer in [src-tauri/tauri.conf.json](../src-tauri/tauri.conf.json), with:

- productName: IR POS
- identifier: com.irfusions.irpos
- version: 1.0.0
- bundle publisher: IR Fusions
- bundle targets: ["nsis", "dmg", "app"]

## Build commands

Run the project build and packaging commands on a supported Windows host:

```bash
npm install
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
cargo install tauri-cli --version ^2
npm run tauri build
```

Expected Windows output on a Windows build host:

- a native .exe installer through the Tauri NSIS bundler
- or a Windows bundle generated by a supported Tauri Windows environment

## Actual artifacts generated in this environment

The following artifacts were generated on the current host during verification:
